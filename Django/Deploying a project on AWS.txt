Preparing our server for deployment:
1- Installing updates:
   sudo apt-get update   
2- Installing Nginx (Our website manager)
   sudo apt install nginx   
3- Cloning our project inside our Ubuntu server system:
   git clone clone_link   
4- Installing venv so we can create a virtual environment:
   sudo apt-get install python3-venv   
5- Navigate to your repo directory and create a virtual environment:
   cd repo_name
   python3 -m venv env_name
   source env_name/bin/activate   
6- Installing dependencies inside our environment:
   "pip install django==2.2 #it must be the same inside the (requirements.txt)
   pip install bcrypt
   pip install gunicorn"
	or make this:
   "pip install --upgrade pip setuptools
   pip install -r requirements.txt
   pip install gunicorn"  
7- Installing vim terminal-based text editor:
   sudo apt install vim   
8- Navigate to the directory where settings.py lives and start editing it:
   cd repo_name/project_name
   sudo vim settings.py   

inside settings.py
modify these lines
   At the very top of the file (on line 1), add:
   import os
   DEBUG = False
   ALLOWED_HOSTS = ['{{yourEC2.public.ip}}'] # keep the quotes!
   STATIC_ROOT = os.path.join(BASE_DIR, "static/") # add this line at the bottom; don't replace any existing lines! 
   
   -Save and quit: Esc, wq, enter

Setting up Gunicorn, our server process manager:
1- First we test it inside our repo directory:
   cd repo_name
   gunicorn project_name.wsgi
   If the process ran correctly, all good. CTRL+C and deactivate your virtual env. 

2- Now, we have to set up gunicorn as a service so that it can start up whenever our system reboots. 
   sudo vim /etc/systemd/system/gunicorn.service
   Copy and paste the following code and modify as needed:
[Unit]
Description=gunicorn daemon
After=network.target

[Service]
User=ubuntu
Group=www-data
WorkingDirectory=/home/ubuntu/{{myRepoName}}
ExecStart=/home/ubuntu/{{myRepoName}}/{{venv_name}}/bin/gunicorn --workers 3 --bind unix:/home/ubuntu/{{myRepoName}}/{{projectName}}.sock {{projectName}}.wsgi:application

[Install]
WantedBy=multi-user.target

Save and quit: Esc, :wq, enter

Now, we can enable it to start on boot:
sudo systemctl daemon-reload
sudo systemctl restart gunicorn
sudo systemctl status gunicorn


Setting up Nginx, our server manager:
1- We must first create a file to configure our web server:
	sudo vim /etc/nginx/sites-available/project_name
server {
    listen 80;
    server_name {{yourEC2.public.ip}};

    location = /favicon.ico { access_log off; log_not_found off; }
    location /static/ {
        root /home/ubuntu/{{myRepoName}};
    }

    location / {
        include proxy_params;
        proxy_pass http://unix:/home/ubuntu/{{myRepoName}}/{{projectName}}.sock;
    }
}

	Save and quit: Esc, :wq, enter

2- Now, we create a link to the file we created above to let Nginx know which settings to use:
   sudo ln -s /etc/nginx/sites-available/{{projectName}}/etc/nginx/sites-enabled   
3- Testing it to make sure the link was successfull:
   sudo nginx -t   
4- Now that we have our custom configuration, we may remove the Nginx default configuration:
   sudo rm /etc/nginx/sites-enabled/default   
5- Now we restart gunicorn:
   sudo systemctl restart gunicorn   
6- Now we must set the correct permissions for our socket files so that our server can access it:
sudo chmod 664 /home/ubuntu/{{myRepoName}}/{{projectName}}.sock
sudo chown www-data:www-data /home/ubuntu/{{myRepoName}}/{{projectName}}.sock   
7- Now we add Nginx to the user group that owns the socket file:
   sudo usermod -aG ubuntu www-data 

8- Now, we restart Nginx:
sudo service nginx restart
sudo systemctl daemon-reload
sudo systemctl restart nginx
