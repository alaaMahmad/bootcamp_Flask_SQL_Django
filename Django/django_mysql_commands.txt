===================================================================
DJANGO & MYSQL WORKBENCH INTEGRATION CHEAT SHEET
===================================================================

1. INSTALL VIRTUAL ENVIRONMENT & MYSQL DRIVER
-------------------------------------------------------------------
# Activate your virtual environment
source venv/Scripts/activate      # On Windows Git Bash


# Install the MySQL database driver for Python
pip install mysqlclient


2. CREATE DATABASE IN MYSQL WORKBENCH
-------------------------------------------------------------------
Open MySQL Workbench, connect to your local MySQL instance, 
and run the following SQL command in a Query Tab:

CREATE DATABASE django_mysql_app;

OR

CREATE DATABASE django_mysql_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;


3. REGISTER APP & CONFIGURE CREDENTIALS (django_mysql_proj/settings.py)
-------------------------------------------------------------------
# A. Add app to INSTALLED_APPS:
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'django_mysql_app',  # Registered app
]

# B. Update DATABASES configuration:
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'django_mysql_app',        # MySQL Database Name
        'USER': 'root',                    # MySQL Username
        'PASSWORD': 'your_mysql_password', # MySQL Password
        'HOST': 'localhost',
        'PORT': '3306',
    }
}


4. DEFINE USER MODEL (django_mysql_app/models.py)
-------------------------------------------------------------------
from django.db import models

class User(models.Model):
    first_name = models.CharField(max_length=255)
    last_name = models.CharField(max_length=255)
    email_address = models.CharField(max_length=255)
    age = models.IntegerField()
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    def __str__(self):
        return f"{self.first_name} {self.last_name}"


5. GENERATE & APPLY MIGRATIONS
-------------------------------------------------------------------
# Build migration files specifically for your app
python manage.py makemigrations django_mysql_app

# Apply migrations to generate tables inside MySQL Workbench
python manage.py migrate


6. INTERACTING WITH DATA VIA DJANGO SHELL
-------------------------------------------------------------------
# Launch interactive shell
python manage.py shell

# Inside shell:
from django_mysql_app.models import User

# Create a record using English transliterated names
User.objects.create(
    first_name="Alaa",
    last_name="Ahmad",
    email_address="alaa@example.com",
    age=24
)

# Fetch all users from MySQL
User.objects.all()

# Exit shell safely to release locks
exit()


7. VIEWING DATA IN MYSQL WORKBENCH
-------------------------------------------------------------------

SELECT * FROM django_mysql_app.django_mysql_app_user;

OR

1. Open MySQL Workbench and refresh SCHEMAS.
2. Expand database: django_mysql_app -> Tables.
3. Right-click table: 'django_mysql_app_user'
4. Select: 'Select Rows - Limit 1000'
