===================================================================
DJANGO QUICK-START CHEAT SHEET
===================================================================

1. CREATE VIRTUAL ENVIRONMENT
-------------------------------------------------------------------
python -m venv myenv


2. ACTIVATE VIRTUAL ENVIRONMENT
-------------------------------------------------------------------
source myenv/Scripts/activate


3. INSTALL DJANGO
-------------------------------------------------------------------
pip install django


4. NAVIGATE TO WORKSPACE DIRECTORY
-------------------------------------------------------------------
cd D:\bootcamp\Flask_SQL_Django\Django\django_intro


5. CREATE A NEW DJANGO PROJECT
-------------------------------------------------------------------
django-admin startproject project_name
# Note: Avoid using '.' shortcut if creating nested directory structures.


6. ENTER PROJECT DIRECTORY
-------------------------------------------------------------------
cd project_name


7. CREATE A NEW DJANGO APP
-------------------------------------------------------------------
python manage.py startapp app_name

* IMPORTANT WINDOWS NOTE:
  Windows paths are case-insensitive. Never give your app the exact 
  same name as your project folder (e.g., project 'Time_Display' and 
  app 'time_display' will collide). Use prefixes like 'app_time_display'.


8. RUN DATABASE MIGRATIONS (Required for Django Sessions)
-------------------------------------------------------------------
python manage.py migrate


9. RUN THE DEVELOPMENT SERVER
-------------------------------------------------------------------
python manage.py runserver

[D] Define View Functions & Session Logic (app_name/views.py):
-------------------------------------------------------------------
from django.shortcuts import render, redirect

def index(request):
    if 'counter' not in request.session:
        request.session['counter'] = 0
    request.session['counter'] += 1
    return render(request, 'index.html')

def process(request):
    if request.method == 'POST':
        request.session['name'] = request.POST.get('name')
        request.session['location'] = request.POST.get('location')
        request.session['skills'] = request.POST.getlist('skills') # For checkboxes
        return redirect('/result')
    return redirect('/')

def result(request):
    return render(request, 'result.html')

def destroy_session(request):
    request.session.clear()
    return redirect('/')

===================================================================
TEMPLATE SYNTAX SUMMARY
===================================================================

1. Loading Static Files & CSS Linking:
-------------------------------------------------------------------
{% load static %}
<link rel="stylesheet" href="{% static 'css/style.css' %}">


2. Forms & CSRF Token:
-------------------------------------------------------------------
<form action="/process" method="POST">
    {% csrf_token %}
    <input type="text" name="name" class="form-control" required>
    <button type="submit" class="btn btn-primary">Submit</button>
</form>


3. Accessing Sessions & Variables in Templates:
-------------------------------------------------------------------
<p>Name: {{ request.session.name }}</p>
<p>Comment: {{ request.session.comment|default:"N/A" }}</p>

{% if request.session.skills %}
  <ul>
    {% for skill in request.session.skills %}
      <li>{{ skill }}</li>
    {% endfor %}
  </ul>
{% else %}
  <p>No skills selected</p>
{% endif %}
